# QLabs 场景解耦说明

本目录提供四个主要代码文件，用于将原先混合在一起的公路场景、十字路口场景与侧方位停车道路场景拆开维护：

- road_scene.py：只负责公路本体的几何、路面和标线生成。
- intersection_scene.py：只负责十字路口、斑马线、红绿灯模型和非阻塞灯控。
- paralleling_parking.py：只负责侧方位停车道路、车位和预览辅助图的生成。
- scene_runner.py：总入口脚本，负责将公路、十字路口和侧方位停车道路拼接成完整演示场景。

这些文件的目标是让你在后续实验中可以独立测试道路、独立测试十字路口、独立测试停车道路，或者通过总入口快速组合使用，而不需要再把全部逻辑堆在一个脚本里维护。

## 1. 文件职责

### road_scene.py

该文件封装了连续公路的构建逻辑，包括：

- 平路
- 缓上坡
- 中段平路
- 平滑 S 弯
- 后段平路
- 缓下坡
- 末端过渡直路
- 双向道路标线

核心接口：

- RoadSceneConfig：道路参数配置对象。
- build_road_scene(qlabs, config, cleanup_first=False)：创建道路场景。
- RoadSceneResult.anchor：道路末端锚点，可直接交给十字路口库进行拼接。

默认配置：

- 每侧 3 车道
- 车道宽度 3.5 m

支持配置的车道数：

- 每侧 1 车道
- 每侧 2 车道
- 每侧 3 车道
- 每侧 4 车道

也就是总共支持：双向单车道、双向两车道、双向三车道、双向四车道。

### intersection_scene.py

该文件封装了十字路口相关逻辑，包括：

- 对称十字路口路面
- 三个或四个方向的直线道路延伸
- 路口入口标线留白
- 四方向斑马线
- 自定义红绿灯几何模型
- 红绿灯非阻塞循环控制

核心接口：

- IntersectionConfig：路口参数配置对象。
- build_intersection_scene(...)：创建十字路口。
- IntersectionSceneResult.update_traffic_lights(...)：推进红绿灯状态，不会阻塞主线程。

### paralleling_parking.py

该文件封装了侧方位停车道路的构建逻辑，包括：

- 可拼接的停车道路区域
- 侧方位停车位边界
- 停车位入口虚线
- 可选的 Matplotlib 俯视预览

核心接口：

- ParkingRoadSceneConfig：停车道路参数配置对象。
- setup_map(...)：创建停车道路场景，可通过 anchor 接到其他道路或路口之后。

### scene_runner.py

该文件是组合入口：

1. 连接 QLabs。
2. 清理旧场景。
3. 创建公路场景。
4. 读取道路末端锚点。
5. 创建十字路口场景。
6. 从右转出口锚点继续拼接侧方位停车道路。
7. 持续驱动红绿灯循环更新。

## 2. 快速使用

### 仅测试公路库

直接运行：

```python
python road_scene.py
```

该入口会只创建公路，不创建路口和红绿灯。

### 仅测试十字路口库

直接运行：

```python
python intersection_scene.py
```

该入口会生成一个独立十字路口，并在有限时长内演示红绿灯循环。

### 运行完整组合场景

直接运行：

```python
python scene_runner.py
```

该入口会将公路和路口拼接起来，形成完整场景。

## 3. 公路库参数说明

常用参数位于 RoadSceneConfig 中。

### 车道参数

- lanes_per_direction：每个方向的车道数，只支持 1、2、3、4。
- lane_width：单车道宽度，默认 3.5。

### 道路形态参数

- flat1_length：前段平路长度。
- up_length：上坡长度。
- flat2_length：上坡后的平路长度。
- s_curve_length：S 弯长度。
- s_curve_amplitude：S 弯横向偏移幅值。
- flat3_length：S 弯后的平路长度。
- down_length：下坡长度。
- flat_end_length：道路尾段平路长度。
- terminal_straight_length：道路末端为拼接路口预留的直线路段长度。

### 标线参数

- line_width：标线宽度。
- line_height_offset：标线抬高量，避免和路面重叠闪烁。
- yellow_gap：双黄线间距。
- terminal_marking_trim_end：末端直路标线预留留白长度，常用于路口前停止继续画线。

### 示例：创建双向四车道

```python
from road_scene import RoadSceneConfig, build_road_scene

config = RoadSceneConfig(
    lanes_per_direction=4,
    lane_width=3.5,
)
result = build_road_scene(qlabs, config=config)
```

### 示例：创建双向单车道

```python
config = RoadSceneConfig(
    lanes_per_direction=1,
    lane_width=3.2,
)
result = build_road_scene(qlabs, config=config)
```

## 4. 十字路口库参数说明

常用参数位于 IntersectionConfig 中。

### 车道相关参数

- lanes_per_direction：每侧车道数，支持 1、2、3、4。
- lane_width：车道宽度，默认 3.5。

### 路口几何参数

- intersection_length：路口本体直线长度，默认跟随总路宽自动计算。
- main_exit_length：主方向出口道路延伸长度。
- side_exit_length：侧方向出口道路延伸长度。
- include_incoming_arm：是否补建南侧来向道路。独立测试路口时建议为 True；和公路拼接时建议为 False，避免重复铺路。

### 斑马线参数

- crosswalk_clear_length：路口入口留白长度。
- crosswalk_outside_offset：斑马线中心相对路口边界的外移距离。
- crosswalk_stripe_length：单条斑马线纹理长度。
- crosswalk_stripe_thickness：条纹厚度。
- crosswalk_stripe_gap：条纹间距。

### 红绿灯参数

红绿灯配置分成三层：

1. TrafficLightStyle：红绿灯的几何尺寸。
2. TrafficLightCycleConfig：红黄绿状态循环顺序、每种状态持续时间、起始状态、Actor ID 起点。
3. traffic_light_offsets：四个方向各自的位置偏移和朝向偏移。

默认情况下，三种颜色的持续时间都是 10 秒。

### 红绿灯偏移接口

traffic_light_offsets 是一个字典，键为：

- south
- north
- west
- east

每个方向对应一个 TrafficLightPlacement，支持：

- longitudinal_shift：沿道路方向前后移动。
- lateral_shift：沿道路横向左右移动。
- yaw_offset_deg：额外偏航角度修正。
- lateral_sign：默认保留内部方向逻辑，一般无需修改。

### 示例：调整南北方向红绿灯位置和角度

```python
from intersection_scene import (
    IntersectionConfig,
    TrafficLightPlacement,
    build_intersection_scene,
)

config = IntersectionConfig(
    lanes_per_direction=3,
    lane_width=3.5,
)
config.traffic_light_offsets["south"] = TrafficLightPlacement(
    lateral_sign=1.0,
    longitudinal_shift=1.5,
    lateral_shift=0.8,
    yaw_offset_deg=15.0,
)
config.traffic_light_offsets["north"] = TrafficLightPlacement(
    lateral_sign=-1.0,
    longitudinal_shift=-1.0,
    lateral_shift=0.5,
    yaw_offset_deg=-10.0,
)

result = build_intersection_scene(qlabs, config=config, center=[0, 0, 0], forward=[0, 1])
```

### 示例：自定义红绿灯时长

```python
from intersection_scene import (
    IntersectionConfig,
    TrafficLightCycleConfig,
    STATE_GREEN,
    STATE_RED,
    STATE_YELLOW,
)

config = IntersectionConfig(
    traffic_light_cycle=TrafficLightCycleConfig(
        sequence=[STATE_RED, STATE_GREEN, STATE_YELLOW],
        durations={
            STATE_RED: 12.0,
            STATE_GREEN: 8.0,
            STATE_YELLOW: 3.0,
        },
        start_state=STATE_RED,
    )
)
```

## 5. 非阻塞灯控说明

当前实现中，红绿灯循环逻辑已经下沉到 intersection_scene.py 内部，不需要主代码再自己维护状态机。

你只需要周期性调用：

```python
result.update_traffic_lights(current_time=time.time())
```

或者显式传入时间步长：

```python
result.update_traffic_lights(delta_time=0.1)
```

这样不会在库内部进入死循环，主线程仍然可以继续执行其他逻辑。

## 6. 组合使用推荐方式

推荐按下面顺序进行组合：

1. 先创建道路。
2. 从道路结果中读取 anchor。
3. 将 anchor 传给十字路口库。
4. 在主循环里周期性更新红绿灯。

示例：

```python
from road_scene import RoadSceneConfig, build_road_scene
from intersection_scene import IntersectionConfig, build_intersection_scene

road_config = RoadSceneConfig(
    lanes_per_direction=3,
    lane_width=3.5,
    terminal_marking_trim_end=4.0,
)
road_result = build_road_scene(qlabs, road_config)

intersection_config = IntersectionConfig(
    lanes_per_direction=road_config.lanes_per_direction,
    lane_width=road_config.lane_width,
)
intersection_result = build_intersection_scene(
    qlabs,
    config=intersection_config,
    anchor=road_result.anchor,
)
```

## 7. 常见问题

### QLabs 无法连接

请确认 QLabs 已经启动，并且可以通过 localhost 建立连接。

### 红绿灯不亮或不切换

当前版本已经做了几项保护：

- 生成后延迟极短时间再设置初始状态。
- 状态未变化时不重复发送相同材质更新。
- 使用库内非阻塞 update 机制，而不是在主代码中写死循环。
- 红绿灯生成失败时只给出警告，不会因为单个灯失败导致整个程序直接崩溃。

如果仍不亮，优先检查：

1. Actor ID 是否与其他场景对象冲突。
2. QLabs 当前版本是否支持基本形体材质动态更新。
3. 主循环是否持续调用了 update_traffic_lights。

### 路口与道路重叠

如果你是从公路末端拼接路口，请确保：

- road_scene.py 中 terminal_marking_trim_end 已预留停止线附近留白。
- intersection_scene.py 中 include_incoming_arm 设为 False。

### 斑马线跨度不合适

斑马线跨度会自动跟随总路宽变化。如果你还需要更细调节，请修改：

- crosswalk_outside_offset
- crosswalk_stripe_length
- crosswalk_stripe_thickness
- crosswalk_stripe_gap

## 8. 后续建议

如果你后续要继续扩展，本结构推荐沿下面方向演进：

1. 将更多道路类型继续放入 road_scene.py，例如连续弯道、匝道、分叉路。
2. 将红绿灯升级为多相位控制，而不是四个方向同相位同步闪烁。
3. 将场景参数进一步整理为实验模板，便于不同实验一键切换。
